# 豆包电脑版（Doubao Desktop）功能架构调研与 `deepseek-desktop` 差距对照报告

> 调研人：许清楚（产品经理） · 日期：2026-07-20
> 调研方式：联网检索（WebSearch）+ 官网/帮助页抓取（WebFetch），仅整理**对外公开**功能与交互，不推测内部工程实现。
> 对照基线：`deepseek-desktop`（Electron + WebContentsView 内嵌 chat.deepseek.com 的桌面薄壳）

---

## 0. 关键结论前置（架构层面的根本差异）

- **豆包电脑版是原生桌面应用**：自带豆包大模型（Seed/2.1 系列）、Agent 执行后端、内置 Chrome 内核浏览器，并非"网页内嵌薄壳"。
- **`deepseek-desktop` 是薄壳**：它只是把 `chat.deepseek.com` 包进 Electron 窗口。因此：
  - **纯桌面外壳交互**（全局快捷键、划词菜单、边缘常驻、截图、翻译注入、主题）——我们可以在 Electron 层直接补齐。
  - **依赖后端模型/服务的能力**（办公任务 Agent、应用生成、图像/视频/音乐生成、云盘、语音通话、AI 播客、多端云同步）——薄壳无法自行提供，除非 `chat.deepseek.com` 网页端已暴露等价能力，或引入外部 API/本地模型。
- **DeepSeek 网页端主打对话/推理**，目前**没有**公开的原生图像/视频/音乐生成、Agent 任务模式、云盘等能力。这是"产品定位差"，不是"壳差"。

> 资料可信度图例：✅ 已确认（官网/官方新闻稿/权威媒体报道）｜🟡 第三方描述（下载站/教程，与官方一致但细节待验）｜❓ 待实机验证

## 1. 豆包电脑版功能架构总览

按模块分层列出。每个功能标注**公开入口**与**交互方式**。

### 1.1 对话核心
| 功能 | 公开入口 | 交互方式 |
|---|---|---|
| 新对话 / 多轮对话 | 首页"新对话"（快捷键 ⇧⌘K） | 输入框回车发送，支持上下文多轮 |
| 专家模式 / 深度思考 | 首页技能栏、设置 | 调用 Seed 2.0 Pro / 2.1 Pro，长链路推理、低幻觉、展示推导过程 |

## 2. 差距对照表

> 聚焦"豆包有、我们缺失或明显偏弱"的项。现状判定：✅已实现 / 🟡弱（部分可用但体验不足）/ ❌缺失。

| # | 功能点 | 豆包是否有 | 我们现状 | 差距说明 |
|---|---|---|---|---|
| 1 | **全局一键唤起主窗**（Alt+空格 式悬浮输入） | ✅ | ❌缺失 | 我们主窗**无一键呼出快捷键**，仅副窗有 Alt+Q。这是日常最高频的体验缺口。 |
| 2 | **AI 划词工具栏**（选中文本即浮菜单） | ✅ | ❌缺失 | 我们无任何"选中即触发"机制，必须手动切窗/截图。 |
| 3 | **常驻桌面边缘 / 图钉置顶** | ✅ | 🟡弱 | 副窗有置顶，但无"主窗钉在屏幕边缘的轻量 HUD"形态。 |
| 4 | 对话浮窗 / 小窗 | ✅ | 🟡弱（副窗近似） | 副窗即小窗，但非"临时浮窗"心智，缺一键浮窗入口。 |
| 5 | 截图提问 | ✅ | ✅已实现 | 我们 Ctrl+Shift+A（豆包 Ctrl+Alt+A）；交互形态基本一致。 |
| 6 | **划词/整页对照翻译** | ✅（划词+整页双语+网页栏） | 🟡弱 | 我们翻译窗口仅"注入对话"，无划词触发、无整页对照、无网页栏。 |
| 7 | AI 搜索（全局/Tab 切换） | ✅ | 🟡弱 | 依赖 DeepSeek 网页联网搜索，无独立"AI 搜索/浏览器搜索"切换与总结层。 |
| 8 | **语音通话** | ✅ | ❌缺失 | 需麦克风采集 + ASR + TTS，薄壳无。 |
| 9 | **会议记录（实时转写）** | ✅ | ❌缺失 | 需系统音频捕获 + ASR。 |
| 10 | **AI 播客** | ✅ | ❌缺失 | 需长文→TTS 播客生成。 |
| 11 | **AI 云盘**（无限容量/视频问答） | ✅ | ❌缺失 | 需云端存储后端，薄壳无。 |
| 12 | **收藏夹**（对话/网页/PDF/视频） | ✅ | ❌缺失 | 我们仅有"提示词模板"，无对话/资料收藏。本地收藏可直接做。 |
| 13 | AI 伴读 / 文档深度解读 | ✅ | 🟡弱 | DeepSeek 网页支持文件对话，但无"伴读/中英对照/边读边问"专属形态。 |
| 14 | 数据分析（批量/图表） | ✅ | 🟡弱 | 取决于 DeepSeek 网页文件分析能力。 |
| 15 | **办公任务模式（Agent 执行）** | ✅ | ❌缺失 | 需 Agent 后端 + 本地操作能力，远超薄壳范围。 |
| 16 | **应用生成（超能模式）** | ✅ | ❌缺失 | 需代码生成+部署后端，超出薄壳。 |
| 17 | **图像/视频/音乐生成** | ✅ | ❌缺失 | DeepSeek 网页无原生多模态生成；属产品定位差。 |
| 18 | **多端云同步** | ✅ | 🟡弱 | 我们仅本地 session 持久化，无跨设备云同步。 |
| 19 | 总结视频 / 实时双语字幕 | ✅ | ❌缺失 | 需视频解析+ASR+TTS。 |
| 20 | 设置项补充（搜索引擎切换/网页外观字体/划词菜单自定义） | ✅ | 🟡弱（已有 28 项含快捷键录制、主题跟随） | 我们覆盖外壳类设置，缺"网页浏览/划词菜单"类。 |
| 21 | 提示词模板 | — | ✅已实现 | 我们已有，无需补。 |

## 3. 实现优先级清单

> 落地可行性分级：**直接做**（Electron 外壳即可）/ **部分可行**（需豆包网页端 selector 或轻量外部 API）/ **需额外能力**（本地模型/外部 API/云后端，或超出薄壳架构不建议做）。

### P0 — 核心体验，应优先（1~2 周可落地）
| 项 | 建议 | 落地可行性 |
|---|---|---|
| 全局一键唤起主窗 | 新增全局快捷键（建议 Alt+空格 或自定义）+ 轻量悬浮输入框，唤起即聚焦、Esc 关闭、不抢焦点 | **直接做**（Electron `globalShortcut` + 透明悬浮 BrowserWindow，复用现有对话 WebContents） |
| AI 划词工具栏 MVP | 全局监听文本选区（overlay/accessibility hook）→ 浮出菜单：提问 / 翻译 / 总结 / 复制；前三项转发至 DeepSeek 对话 | **部分可行**（选区捕获可直接做；"翻译/总结"走 DeepSeek 对话注入即可，无需外部 API） |

### P1 — 重要增强（2~3 周）
| 项 | 建议 | 落地可行性 |
|---|---|---|
| 常驻桌面边缘 / 图钉置顶主窗 | 主窗增加"钉在边缘"模式（置顶+收起为侧条），复用副窗置顶逻辑 | **直接做** |
| 划词/整页对照翻译增强 | 在翻译窗口基础上增加"选中即译"与"对照译文"展示；如需高质量可接外部翻译 API | **部分可行**（走 DeepSeek 对话已近似；高质量对照需外部 API） |
| 对话浮窗形态优化 | 提供"一键浮窗"入口，临时小窗提问后自动归位 | **直接做**（复用副窗/小窗） |

### P2 — 按需评估（多需额外能力或超出薄壳）
| 项 | 建议 | 落地可行性 |
|---|---|---|
| 本地对话收藏夹 | 先实现"收藏本条/整个对话"本地存储与列表（不做云端） | **直接做**（本地即可，性价比高） |
| 设置项补充 | 增加"搜索引擎切换/网页外观字体/划词菜单自定义"等外壳类设置 | **直接做** |
| AI 搜索增强层 | 在 DeepSeek 网页联网基础上，增加结果总结浮层 | **部分可行**（依赖网页端 selector） |
| 语音通话 / 会议记录 / AI 播客 / 总结视频 / 实时字幕 | 需 ASR + TTS + 音频/视频捕获，建议接外部 API（如云端语音服务）或暂缓 | **需额外能力** |
| AI 云盘 / 多端云同步 | 需账号体系 + 云端存储，建议暂缓或接第三方云 | **需额外能力** |
| 办公任务 Agent / 应用生成 / 图像视频音乐生成 | 依赖 Agent/生成后端与模型能力，DeepSeek 网页未提供 | **不建议在薄壳内做**（属产品定位差，需独立后端或换模型） |

## 4. 待确认 / 待实机验证

以下问题需用户在**实机豆包**上确认，避免基于第三方描述误判：

1. ❓ **全局唤起快捷键默认值**：部分教程写 `Alt+空格`，需确认是否与输入法/系统冲突及实际组合。
2. ❓ **划词工具栏的触发范围与禁用粒度**：是否真支持"在此应用禁用"、菜单能否完全自定义顺序。
3. ❓ **"连按三下回车翻译""Tab 切换 AI 搜索/浏览器搜索"** 是否仍有效（仅见于第三方教程）。
4. ❓ **具体版本号与功能开关**：下载站版本号不一致（2.10.11 / 2.11.7），以实机"关于"为准；部分能力（视频生成每日 10 次、专业版额度）需实机核对。
5. ❓ **托盘交互细节**：右键菜单是否仅有"退出"，是否有"显示主窗/设置"等项。
6. ❓ **微信文件自动解析 / 多端同步范围**：跨端同步是否包含对话与生成的文件，需实机验证。
7. ❓ **办公任务模式在免费版的真实可用额度与本地操作授权弹窗形态**。

## 5. 下一步建议（增量实现批次，不写代码）

- **批次 1（P0，约 1~2 周）**：全局一键唤起主窗 + AI 划词工具栏 MVP。补齐"随手就能问"的最高频缺口，投入小、收益大。
- **批次 2（P1，约 2~3 周）**：主窗边缘常驻/图钉置顶 + 翻译与划词增强（选中即译、对照译文）+ 对话浮窗入口优化。
- **批次 3（P2·本地可做的部分）**：本地对话收藏夹 + 设置项补充（搜索引擎切换、网页外观字体、划词菜单自定义）。纯外壳，成本低。
- **批次 4（P2·需外部/云能力，评估后定）**：语音通话、会议记录、AI 播客、AI 云盘、多端云同步。建议先做技术选型（外部 ASR/TTS/云存储 API），再决定是否纳入路线图，或在产品层面明确"薄壳不做"以保持定位清晰。
- **明确不做**：办公任务 Agent、应用生成、原生图像/视频/音乐生成——这些依赖 DeepSeek 网页未提供的模型与后端能力，超出薄壳职责，建议在路线图中标注为"依赖上游 web 能力"。
