## Current state（已完成的全部工作）

### A. 模式切换下拉（普通 / 增强搜索 / 任务）——状态机与交互

* 决定：模式只在「新建对话」或「重启」时复位为普通；对话内/刷新后如实保持当前模式（此前一发消息/刷新就退回普通）。

* 派生模式用 **ExtensionHost 同步内存态**（`getWebToolsState().web_search` + `getShellLocalEnabled()`），**禁用**异步 `extensionManager.getWebToolsEnabled()`（写入未落盘→误判普通），见 [main.ts](src/main/main.ts) web-view-ready 钩子。

* 启动仅复位一次普通（`chatModeStartupResetDone`），不再按「URL 无 id」强制回普通。

* 刷新（did-navigate）时清 3s 节流强制重同步；online/task 时再 `injector.setSmartSearch(wc,false)` 重关智能搜索，见 [main.ts](src/main/main.ts)。

* 切会话不再重开智能搜索：[WindowManager.syncChatToggles](src/main/windows/WindowManager.ts) 读页面 `__dsChatMode`，online/task 时强制 `smartSearch=false`。

* 假 NEW\_CONV 修复：新建对话 watcher 加守卫（点模式 UI 不当作新建 + 文本长度 >50 判错），见 [Injector.ts](src/main/inject/Injector.ts) `injectNewConversationWatcher`。

* 任务/增强搜索 + 主窗口/副窗口：

  * 副窗口（窄视口）二级菜单改为**点击当前已选模式项→原位进入子菜单（「← 返回」）**，不悬浮侧栏（防窗缘截断）。悬浮监听始终挂载，是否生效由 `placeXxx` 按运行时视口宽度判断。

  * 修复了主副切换后 `display` 被清导致的图标/文字挤一块（还原时显式 `display='flex'`）。

* 模式项**鼠标悬浮解释**（延迟 350ms、显示在按钮上方、进入任一二级菜单即立即消失、z-index 同菜单）：

  * 普通模式：原生网页版问答

  * 增强搜索：增加网络搜索和链接解析工具，多轮搜索结果更加准确

  * 任务模式：调用python控制本地电脑，编辑读取本地文件，执行各种电脑操作
